            Songs from a playlist go in a subfolder named after it. The library lives in a .tabz folder next to tabz.exe.

            Gemini API key (optional)

            With a key, Gemini also reads each video's title and description for the song, artist, capo, tuning and tempo. Everything works without one. The key is stored only in tabz's own settings file.
