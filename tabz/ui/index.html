From YouTube

Paste a play-along video or a playlist, or search for a song. tabz finds the tab on screen and turns it into bars you can read and print.

From your files

          Gemini API key (optional)

          With a key, Gemini also reads each video's title and description for the song, artist, capo, tuning and tempo, and picks the best backing track from the search results. Everything works without one. The key is stored only in tabz's own settings file.
